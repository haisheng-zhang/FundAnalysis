# 基金透视 (Fund Insight)

根据基金最新季报重仓股 + 新浪财经实时行情，秒级估算基金当日实时涨幅。

前后端分离架构：前端 **Next.js**，后端 **FastAPI + AkShare**，部署在 Vercel + Render。

## 核心特性

- **实时估值** — 调用新浪财经批量行情接口，支持全品种（含科创板688xxx），非交易时段自动返回最后收盘数据
- **持仓透视** — 展示基金最新季报重仓股、各股占比、涨跌幅及对基金净值的贡献度
- **热门基金** — 近1月涨幅前10（去除同系列A/C重复份额），每日刷新
- **最近浏览** — 自动记录浏览历史，支持一键重新查看，可清空
- **AI 诊断（即将上线）** — 持仓风格诊断、行业赛道解读、风险等级评级，¥19/年早鸟预约中
- **交易时段自动刷新** — 交易时间内（9:30–11:30、13:00–15:00）每60秒静默刷新估值

## 数据来源

| 数据 | 来源 |
|------|------|
| 基金持仓（季报） | AkShare / 东方财富 |
| 实时股票行情 | 新浪财经 (`hq.sinajs.cn`) |
| 基金搜索列表 | AkShare |
| 热门基金排名 | AkShare / 东方财富 |
